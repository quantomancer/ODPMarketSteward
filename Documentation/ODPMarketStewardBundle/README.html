ODP Market Steward Bundle

This directory contains the responsibility-separated specification package for the FXLive Market Data Demo and the planned ODP Market Steward ChatGPT MCP App and Cloudflare service.

The package contains one official ODP-family artifact, the ODPS 4.1 product contract; OpenAPI is a companion standard and the other YAML files are explicitly classified project contracts. Functional Requirements Draft 0.5 and Technical Requirements Draft 0.3 define the current acceptance and delivery baseline. Detailed Level Design Draft 0.3 translates that baseline into non-normative modules, interfaces, sequences, tests, release gates, and implementation work packages. A local MCP vertical slice and deterministic domain foundations exist, including the approved descriptive OHLC calculator, evidence-gated prior-bar continuity/gap evaluation, and ADR-004 plausibility baseline; the Durable Object acknowledgement flow, remaining five domain handlers, finished Apps SDK component, GPT-5.6 integration, Cloudflare deployment, and public /mcp endpoint do not yet exist.
